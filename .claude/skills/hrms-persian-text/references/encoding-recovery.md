# تشخیص و بازیابی خرابی کدگذاری فارسی

## چطور خراب می‌شود

سناریوی واقعی این پروژه: فایل UTF-8 فارسی با یک دستور خط فرمان بازنویسی شد؛ متن یک‌بار
به CP1252 رمزگذاری و بعد به‌عنوان UTF-8 خوانده شد (و بار دوم)، نتیجه: همهٔ متن فارسی به
دنبالهٔ «Ù3⁄4Ø±ÙˆÙ1» تبدیل شد و کل رابط ناخوانا.

## نشانه‌ها

| نشانه | معنا |
| --- | --- |
| شمار نویسهٔ فارسی (`\u0600-\u06FF`) صفر یا خیلی کم | متن از دست رفته |
| نویسهٔ `Ã` (U+00C3) و «Ù» زیاد | موجی‌بکه: UTF-8 که به‌عنوان CP1252 خوانده/نوشته شده |
| نویسهٔ `\ufffd` | بایت نامعتبر در فایل؛ اگر نشانهٔ یک نویسهٔ نمایشی شکسته باشد (مثل `«`) با همان نویسه جایگزینش کن، وگرنه از نسخهٔ سالم برگردان |
| BOM (`EF BB BF`) | نوشتن با ابزاری که BOM می‌گذارد؛ در فایل‌های متنی پروژه BOM نمی‌خواهیم — **جز `.ps1`/`.cmd`/`.bat`** که PowerShell 5.1 برای خواندن UTF-8 به BOM نیاز دارد |

سنجش خودکار:

```bash
node .claude/skills/hrms-persian-text/scripts/check-fa.mjs docs server/internal
```

## بازیابی

1. **اگر گیت دارید، همیشه از گیت بگیرید** (کم‌ریسک‌ترین راه):

```bash
git show <commit>:<path> > <path>     # یا: git checkout -- <path>
```

2. **بازگردانی زنجیرهٔ خرابی** (وقتی نسخهٔ سالم در گیت نیست): متن خراب را یک‌بار به CP1252
   رمزگذاری و دوباره به UTF-8 بخوانید؛ اگر دوبار خراب شده باشد، همین کار را دوبار تکرار
   کنید. این کار متن را بایت‌به‌بایت برمی‌گرداند:

```python
import sys
p = sys.argv[1]
t = open(p, encoding="utf-8").read()
for _ in range(2):                     # به تعداد لایه‌های خرابی
    try:
        t = t.encode("cp1252").decode("utf-8")
    except UnicodeError:
        break                          # لایهٔ بعدی وجود ندارد
open(p, "w", encoding="utf-8", newline="").write(t)   # UTF-8 بدون BOM
```

3. **پس از بازیابی**: همان فایل را با ابزار خواندن ببین، `check-fa.mjs` را اجرا کن و با
   `git diff` مطمئن شو تفاوت فقط همان چند خط عمدی است.

## پیشگیری

- برای متن فارسی همیشه از **ابزار ویرایش فایل** استفاده کن، نه `Set-Content`/`echo` در خط فرمان.
- هرگز فایل فارسی را کامل از راه خط فرمان بازنویسی نکن؛ ویرایش موضعی.
- برای خواندن، `Get-Content` پیش‌فرض PowerShell 5.1 ممنوع (ANSI می‌خواند)؛ از
  `[System.IO.File]::ReadAllText($p, [Text.Encoding]::UTF8)` یا ابزار خواندن فایل.
- پس از هر تغییر، همان چند سطر را دوباره بخوان و شمار فارسی/`Ã` را بسنج.
- در نوشتن با پایتون: `open(path, "w", encoding="utf-8", newline="")` و از `encoding="utf-8-sig"` استفاده نکن.
