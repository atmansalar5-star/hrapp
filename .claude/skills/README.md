# کتابخانهٔ اسکیل پروژهٔ HRMS

این پوشه، **اسکیل‌های عامل (Agent Skills)** این پروژه است: دستورالعمل‌های کوتاه و اجرایی که
هر عامل هوش مصنوعی (Claude Code، DeepSeek Harness، Cursor، Codex و…) پیش از انجام کارِ همان
حوزه بار می‌کند تا همان روش، همان فرمان‌ها و همان قاعده‌های این مخزن را به‌کار ببرد.

قالب بر پایهٔ استاندارد باز [Agent Skills](https://agentskills.io/specification) است:
هر اسکیل یک پوشه با فایل `SKILL.md` و پیشوند YAML (`name` و `description`) و متن دستورها؛
پوشه‌های اختیاری `scripts/`، `references/` و `assets/` هم مجازند.

## فهرست اسکیل‌ها

| اسکیل | کِی بار شود |
| --- | --- |
| `hrms-verify` | پیش از هر کامیت/تحویل؛ `make check`، انحراف قرارداد، مرز ماژول، CI قرمز |
| `hrms-parameter` | «این عدد را پارامتری کن»، ضریب/سقف/درصد تازه، تغییر مقدار پیش‌فرض شرکت |
| `hrms-module` | ماژول تازه، صفحهٔ تازه، نوع رکورد و گردش‌کار جدید |
| `hrms-persian-text` | نوشتن/اصلاح متن فارسی، راست‌چینی، ارقام و تاریخ شمسی، موجی‌بکه |
| `hrms-compensation` | مدل ۴پی/جی‌بیست، صندوق نفت، دستورالعمل ۳۴۰۰۶، فیش ماهانه، روش پرداخت |
| `hrms-pentest-package` | ساخت بستهٔ تست نفوذ، زیپ استاندارد، حذف اسرار/دیباگ |
| `hrms-deploy-windows` | سرور بالا نیست، ری‌استارت سرویس، دام باتری، آماده‌بودن `/readyz` |
| `hrms-office-export` | گزارش Word/Excel، سند ارائه، PDF فارسی |

## اسکریپت‌های همراه

| اسکریپت | کار |
| --- | --- |
| `.claude/skills/hrms-verify/scripts/gates.mjs` | اجرای ترتیبی دروازه‌ها با خلاصهٔ زمانی (`--with-tests` / `--all`) |
| `.claude/skills/hrms-persian-text/scripts/check-fa.mjs` | سنجش کدگذاری فارسی کل مخزن یا یک مسیر (BOM، موجی‌بکه، `\ufffd`) |
| `.claude/skills/hrms-pentest-package/scripts/verify-package.mjs` | بازمحاسبهٔ `MANIFEST.sha256` بستهٔ تحویلی + جست‌وجوی الگوهای ممنوع |

این‌ها ابزارِ **عامل** هستند و جزو دروازه‌های CI نیستند (بجز `tools/skills/check-skills.mjs`
که در `make verify` اجرا می‌شود).

## قاعدهٔ کار

1. **پیش از شروع کار**، اسکیل مربوط را بخوان (در Claude Code خودکار بار می‌شود؛ در
   DeepSeek Harness/عامل‌های دیگر محتوای `SKILL.md` را بخوان).
2. اسکیل جای `AGENTS.md` را نمی‌گیرد؛ `AGENTS.md` قاعده‌های کلی مخزن است و این‌ها روش کارِ
   هر حوزه. اگر تعارضی دیدی، `AGENTS.md` مقدم است.
3. هر اسکیل باید **کوتاه و اجرایی** بماند (زیر ~۱۲۰ خط)؛ جزئیات طولانی را در
   `references/<topic>.md` همان اسکیل بگذار و از `SKILL.md` به آن ارجاع بده.

## افزودن اسکیل تازه

```bash
mkdir -p .claude/skills/<skill-name>
# SKILL.md با پیشوند name/description بنویس، سپس:
node tools/skills/check-skills.mjs     # اعتبارسنجی قالب (نام، توضیح، ساختار)
```

قاعده‌های قالب: `name` هم‌نام پوشه، فقط حروف کوچک لاتین/رقم/خط تیره (≤۶۴ نویسه)؛ `description`
غیرخالی و ≤۱۰۲۴ نویسه که **چه کاری** و **کِی** را می‌گوید (همین متن مبنای انتخاب اسکیل است).

## آوردن اسکیل از بیرون

- مجموعهٔ رسمی Anthropic: <https://github.com/anthropics/skills> (بخشی از آن Apache-2.0) و
  افزونهٔ Claude Code با `/plugin marketplace add anthropics/skills`.
- استاندارد و فهرست کلاینت‌ها: <https://agentskills.io>.
- اگر اسکیلی از بیرون می‌آوری: **پیش از کپی** مجوزش را بررسی کن، منبع و مجوز را در پیشوند
  (`license:`) بنویس، و اگر با قواعد این مخزن تعارض داشت، نسخهٔ سازگارشده را با ارجاع به
  منبع اصلی نگه دار. اسکیل‌های عمومی سند/جدول معمولاً در محیط اجرایی هم موجودند
  (`office-docx`، `office-xlsx`، …) و نیازی به تکرارشان در مخزن نیست.
