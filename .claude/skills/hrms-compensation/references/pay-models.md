# چهار مدل پرداخت — جزئیات

## جدول تصمیم

| پرسش | پاسخ |
| --- | --- |
| کدام مدل برای این کارمند فعال است؟ | رکورد `employeePayModel` (صفحهٔ «روش پرداخت کارکنان») |
| مدل انتخابی اثر دارد؟ | فقط اگر پرچم همان مدل روشن باشد (`*.payroll.apply`) |
| مبلغ فیش از کجا می‌آید؟ | موتور قواعد همان مدل + کسور قانونی مشترک |

## ۱) مدل جاری (`payroll`)

- اقلام از `payItems` (کد، نوع محاسبه، مبنا، فرمول) و پارامترهای گروه «حقوق و دستمزد».
- موتور: `rules.ComputePayroll(input, params)` → ناخالص، بیمه، مالیات، خالص.
- فیش: `GET /api/v1/payroll/payslip?employee=` و رکورد `payrollRuns`/`payslips`.

## ۲) صندوق بازنشستگی نفت (`oil`)

- قاعده: `rules.ComputeOilPayslip` (`server/internal/rules/oilpay.go`).
- ساختار: پایهٔ حقوق + فوقالعادهٔ بدی آب و هوا (٢٥٪) = مبنای فوقالعاده‌ها؛ بقیهٔ اقلام درصدی از همان مبنا.
- پارامترها: `oilpay.*` (نرخ‌ها، جدول‌های ۱ تا ۳، سهم صندوق، معافیت مالیاتی).
- API: `GET /api/v1/payroll/oil-payslip-defaults`، `POST /api/v1/payroll/oil-payslip`.
- رکورد فیش: `oilPayslips` (پیشوند `OILP`).

## ۳) دستورالعمل ۳۴۰۰۶ (`comp34006`)

- قاعده: `rules/comp34006.go` — مبنای «امتیاز × ضریب ریالی».
- ۱۸ قلم با کد رسمی سند:

| کد | قلم | صورت محاسبه |
| --- | --- | --- |
| ۳۴۶۰۱ | حق گرید شغلی | امتیاز گرید شغلی × ضریب ریالی (منهای ۵٪ بابت هر گرید کسر صلاحیت) |
| ۳۴۶۰۲ | پایهٔ سنواتی | مبلغ مصوب |
| ۳۴۶۰۳ | پست استراتژیک | امتیاز پست × ضریب پست (۱ / ۰٫۵ / ۰٫۲۵ / ۰) × ضریب ریالی |
| ۳۴۶۰۴ | گرید شخصی | امتیاز گرید شخصی × ضریب ریالی |
| ۳۴۶۰۵ | نقش | امتیاز نقش × درصد نوع نقش (۵۰/۳۰/۲۰) × ضریب ریالی |
| ۳۴۶۰۶ | جذب بازار کار | حداکثر معادل گرید شخصی، با تصویب |
| ۳۴۶۰۷ | منطقه | سهم جدول ۵ (۶۸٫۷۵٪ تهران / ۱۰۰٪ ماهشهر) + درصد حق گرید شغلی (۵۵٪ / ۸۰٪) |
| ۳۴۶۰۸ | پاداش عملکرد | درصد پارامتری از حقوق پایه |
| ۳۴۶۰۹–۳۴۶۱۲ | ثابت ماهانه، عائله‌مندی، مسکن، خواربار | مبالغ مصوب |
| ۳۴۶۱۳ | تفاوت تطبیق | صفر (طرح G2025) |
| ۳۴۶۱۴ | اضافه‌کاری | (حقوق پایه ÷ روزهای ماه ÷ ۷٫۳۳) × ۱٫۴ × ساعت |
| ۳۴۶۱۵ | نوبت‌کاری | (حقوق پایه ÷ روزهای ماه) × درصد شیفت × روزها |
| ۳۴۶۱۶ | مأموریت | یک روز حقوق پایه برای هر روز |
| ۳۴۶۱۷ | اقماری | فوق‌العادهٔ منطقه ÷ ۱۴ برای هر روز |
| ۳۴۶۱۸ | تعطیل‌کاری | ۴۰٪ روزهای هفته و ۸۰٪ جمعه، علاوه بر حقوق آن روز |

- فیش: `rules.Comp34006PayslipFor` → اقلام + کسور (بیمه/مالیات/سایر) + خالص + هزینهٔ کارفرما.
- رکورد فیش: `comp34006Payslips` (پیشوند `C346`)، چرخهٔ پیش‌نویس → تأیید → صدور → پرداخت.
- پارامترها: ۵۱ کلید `comp34006.*` (جدول‌ها، ضرایب، مناطق، شیفت‌ها، مبالغ سالانه).

## ۴) مدل ۴پی (`fourp`)

- قاعده: `rules/compensation.go` — طراحی بسته، نه محاسبهٔ فیش.
- خروجی: پرداخت هدف = میانهٔ باند × ضریب شایستگی × ضریب عملکرد، با مهار کف/سقف و سقف افزایش.
- مدل جی‌بیست (`rules/g20.go`): ۲۰ شاخص در چهار خانواده و طبقهٔ A–E.
- پارامترها: `compensation.*` و `compensation.g20.*`.

## کسور قانونی (مشترک)

```go
stat := rules.StatutoryDeductions(gross, payrollParams, veteran)
// stat.InsuranceBase/Emloyee/Employer, stat.TaxableIncome, stat.Tax
```

- سقف بیمه، نرخ سهم کارمند/کارفرما، معافیت و پله‌های مالیات: پارامترهای گروه «حقوق و دستمزد».
- امتیاز ایثارگری (معافیت مالیاتی و کسور) از پروندهٔ تأییدشده می‌آید، نه از درخواست.
- خالص = ناخالص − بیمهٔ سهم کارمند − مالیات − سایر کسور.
