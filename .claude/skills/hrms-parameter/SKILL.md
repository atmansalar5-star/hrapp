# پارامتری‌کردن یک عدد در HRMS

قاعدهٔ پروژه: **هیچ عدد سیاستی داخل کد نمی‌ماند.** هر عددی که شرکت می‌تواند عوض کند باید
کلید پارامتر داشته باشد، مقدار پیش‌فرضش در قرارداد باشد و مسیر خواندنش آزمون داشته باشد.

## گام‌ها

1. **کلید را تعریف کن** در `contracts/organizations.json` داخل `defaultParams`:

```json
{ "key": "comp34006.shift.companyPercent", "titleFa": "درصد توافقی نوبت‌کاری شرکت",
  "value": "35", "unitFa": "٪", "groupFa": "نظام جبران خدمات ۳۴۰۰۶" }
```

قواعد نام‌گذاری: `<حوزه>.<موضوع>.<ویژگی>`، لاتین و نقطه‌ای (`payroll.overtimeFactor`،
`compensation.band.basePercent`). `groupFa` همان گروهی است که در صفحهٔ پارامترهای سازمانی
دیده می‌شود؛ گروه‌های موجود را با `Select-String '"groupFa"' contracts/organizations.json` ببین.

2. **بازتولید کن** (خروجی‌های تولیدی دستی ویرایش نمی‌شوند):

```bash
node tools/gen/gen.mjs && node tools/gen/gen.mjs --check
```

3. **در موتور قواعد بخوان.** دو الگوی جاافتاده:
   - `rules/<domain>.go`: تابع `ParamsFromValues(map[string]float64)` با `set("key", func(v float64){...})`
     و **بازهٔ معقول** (مقدار بیرون بازه ⇒ پیش‌فرض دست‌نخورده می‌ماند).
   - ماژول: خواندن پارامترهای شرکت با پیشوند (`strings.HasPrefix(p.Key, "comp34006.")`) و
     ساختن struct پارامتر از `deps.Org.Params`.

اگر عدد در `collectParams` گروه «حقوق و دستمزد» خوانده می‌شود (`server/internal/modules/payroll/handlers.go`)،
کلید باید **بی‌پیشوند** باشد (`insurance.employeeRate`، `tax.exemption`) چون همان‌جا نگاشت می‌شود.

4. **پیش‌فرض = مقدار فعلی کد.** مقادیر پیش‌فرض را طوری بگذار که رفتار امروز عوض نشود؛ سپس
   با آزمون ثابت کن مقدار پیش‌فرض همان قبلی است و مقدار تازه اثر می‌گذارد.

5. **آزمون**: یک آزمون که پارامتر را از متن (با ارقام فارسی هم) می‌خواند و یک آزمون که نشان
   می‌دهد تغییر پارامتر خروجی محاسبه را عوض می‌کند.

## دام‌ها

- کلید تکراری در `defaultParams` ⇒ آخرین برنده می‌شود و رفتار مبهم؛ پیش از افزودن، جست‌وجو کن.
- `value` رشته است؛ ارقام فارسی مجاز است ولی سند تعریف‌شدهٔ پروژه لاتین است.
- عدد درصدی را به‌صورت `٪` در `unitFa` بنویس و در کد همان درصد را تقسیم بر ۱۰۰ کن (نه دو بار).
- اگر پارامتر در گروهی باشد که ماژول نمی‌خواند، اثر نمی‌کند؛ مسیر خواندن را با آزمون ثابت کن.
