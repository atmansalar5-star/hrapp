# سامانه جامع منابع انسانی — طراحی رابط کاربری (HRMS UI Package)

این بسته مطابق «دستورالعمل طراحی رابط کاربری سیستم جامع منابع انسانی» تولید شده و شامل سه خروجی اصلی است:
**پروتوتایپ تعاملی High-Fidelity**، **Wireframeهای Low-Fidelity** و **فلوجارت‌های User Flow** — همه راست‌چین (RTL) و با برچسب‌های فارسی.

## ساختار پوشه‌ها

```
hrapp/
├── prompt.txt                 ← سند دستورالعمل (ورودی)
├── README.md                  ← همین فایل
├── prototype/                 ← پروتوتایپ تعاملی (High-Fidelity)
│   ├── index.html             ← پوسته + صفحه ورود
│   └── js/                    ← داده نمونه، هسته UI، صفحات
│       ├── data.js
│       ├── ui.js              ← RBAC، منوی نقش‌محور، مسیریابی
│       ├── pages.js           ← داشبوردها، کارکنان، پرونده، ساختار سازمانی
│       ├── pages2.js          ← استخدام، حضور و غیاب، مرخصی، تقویم
│       └── pages3.js          ← حقوق، عملکرد، آموزش، رفاه، گزارش، تنظیمات
├── wireframes/                ← Wireframe (Low-Fidelity) — ۷ صفحه حداقلی
│   ├── WF_01_login_employee-dashboard.html
│   ├── WF_02_manager-dashboard_employee-list.html
│   ├── WF_03_employee-profile_leave-form.html
│   └── WF_04_leave-approval.html
├── userflows/                 ← فلوجارت هر نقش (مستطیل=صفحه، لوزی=تصمیم)
│   ├── UF_01_hr-manager.html
│   ├── UF_02_hr-specialist.html
│   ├── UF_03_line-manager.html
│   ├── UF_04_employee.html
│   └── UF_05_admin.html
└── docs/
    └── page-documentation.md  ← مستندسازی فارسی هر صفحه (دستور ۵-۵)
```

## اجرای پروتوتایپ

`prototype/index.html` را در مرورگر باز کنید (بدون نیاز به سرور یا نصب هیچ وابستگی‌ای).
برای بهترین نمایش فونت فارسی، فونت **Vazirmatn** نصب باشد؛ در غیر این صورت Tahoma جایگزین می‌شود.

### حساب‌های آزمایشی (رمز همه: `demo`)

| نام کاربری | نقش |
|---|---|
| `hr.manager` | مدیر منابع انسانی |
| `hr.spec` | کارشناس منابع انسانی |
| `line.mgr` | مدیر واحد |
| `employee` | کارمند |
| `admin` | مدیر سیستم |

## قابلیت‌های پروتوتایپ

- **۵ نقش کاربری** با داشبورد و منوی مجزا — آیتم‌های غیرمجاز از منو حذف می‌شوند (دستور ۳-۱) و ورود مستقیم به صفحه بدون دسترسی مسدود است.
- **۱۰ منوی اصلی** دستورالعمل: داشبورد، کارکنان، استخدام، حضور و غیاب، حقوق و دستمزد، عملکرد، آموزش، رفاه، گزارش‌ها، تنظیمات.
- **تعاملات** (دستور ۴-۳): کلیک منو ← صفحه، کلیک ردیف ← پرونده، «ایجاد» ← فرم، تأیید فرم ← جدول + پیام موفقیت، فیلتر/جستجو ← به‌روزرسانی جدول، تأیید/رد مرخصی ← کسر مانده + پیام.
- **RTL کامل** (دستور ۵-۳): Sidebar در راست، متن راست‌چین، ستون‌های جدول راست‌به‌چپ.
- حالت تیره/روشن، اعلان‌ها، مودال تأیید، Toast، و نمودارهای CSS-محور — بدون هیچ وابستگی خارجی.

## نام‌گذاری فایل‌ها (دستور ۵-۴)

- Wireframe: `WF_[نام-صفحه]_[نقش]` — در عنوان هر فایل رعایت شده است.
- User Flow: `UF_[نام-فرآیند]_[نقش]` — یک فایل به ازای هر نقش.
- Prototype: `PT_HRMS_v1` — پوشه `prototype/` (نسخه ۱٫۰).

> نکته: خروجی نهایی طراحی در ابزار Figma (با پسوند `.fig`) باید توسط طراح بر اساس همین Wireframe/فلوجارت‌ها بازتولید شود؛ این بسته معادل قابل‌اجرا و مرجع کامل آن است.
